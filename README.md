# ATLAS Mk.I — Portable Engineering Terminal

ATLAS Mk.I is a compact, handheld engineering terminal built around an ESP32-S3-WROOM N16R8 platform. The project explores embedded interfaces, sensor-oriented tools, local-first utilities, and a carefully documented portable hardware architecture.

## Target architecture
- ESP32-S3-WROOM N16R8 development board (16 MB flash, 8 MB PSRAM)
- 2.4-inch SPI TFT display, preferably ILI9341, 240×320 portrait
- Protected rechargeable power subsystem, designed and reviewed with appropriate adult/technician oversight
- Modular firmware with clear separation between display, input, storage, and application services

## Development tracks
1. Hardware compatibility and enclosure documentation
2. Firmware foundation and display interface
3. Navigation, settings, and diagnostic utilities
4. Simulation, tests, and build documentation

## Safety and scope
This repository is for educational, general-purpose engineering and embedded-systems work. Battery and power-system assembly must be reviewed and handled by a qualified adult or technician. Do not work on energized or damaged cells.

## Status
Architecture and project portal foundation. Hardware has not been represented as purchased, assembled, or physically tested.
